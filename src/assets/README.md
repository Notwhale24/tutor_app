# Cozy artwork

Artwork was created with the built-in ImageGen tool. The PNG files are bundled
locally; the browser does not call an image service.

- `cozy-farm-art.png`: the originally approved dashboard concept. `CozyArt`
  displays decorative crops while the actual interface stays native HTML.
- `cozy-stitch-art.png`: the approved second concept, with Stitch added to the
  farm banner. Only the banner crop is displayed; the storyboard is not rendered.
- `corgi-sprites.png`: transparent 1536 × 1024 atlas, three columns and two rows.
  Row 1: resting, run 1, run 2. Row 2: carrying 1, carrying 2, sitting.
  The ball is drawn separately as an interactive HTML button. The carrying
  sprites include their own ball, so the separate ball is hidden during return.

## Sprite generation prompt

Production game sprite sheet asset. Exactly SIX equal square cells in a regular
3-column by 2-row grid, transparent background everywhere, no text, no labels,
no grid lines, no ground scene or scenery. Canvas aspect ratio 3:2. Each cell
contains the SAME adorable fluffy orange-and-white Welsh corgi wearing a small
sage green bandana with tiny white daisies. Soft painterly 2.5D cozy farming game
aesthetic, warm light, clean silhouette, high quality delightful character.
Character faces to the RIGHT in ALL SIX cells. Character entirely contained in
its own cell with generous transparent margins of at least 12% on all sides,
same apparent size and baseline within every cell, nothing crosses cell
boundaries. Top row left: corgi lying down resting head on its front paws, eyes
peacefully closed, full body visible. Top row center: side-view corgi running
to the right, legs extended, ears bouncing, joyful expression. Top row right:
same side-view run, opposite legs contracted, a distinct second running
animation phase. Bottom row left: side-view running to the right with a small
CORAL ORANGE tennis ball held in its mouth, legs extended. Bottom row center:
same ball-carrying run with opposite legs contracted. Bottom row right: corgi
sitting facing right with a happy alert expression, head slightly turned toward
camera. Keep character colors, proportions, accessory and lighting exactly
consistent in all six cells. Short little legs, rounded soft orange body, white
belly and muzzle, dark eyes and small dark nose. No floating balls outside
mouth, no shadows outside cell, no watermark. True transparent alpha background.
This is one usable sprite atlas for a small playful pet in a tutor dashboard.
