# Integrated garden artwork

Generated with the built-in image generation tool from the approved painted garden composition. WebP conversion preserves transparency; original PNGs and the source-to-asset manifest remain in the local project backup/work files.

The common art brief: match the reference's detailed warm painterly 3D storybook style, camera perspective and upper-left sunlight. Isolate each complete object on genuine transparency, including gaps between leaves. Use irregular grass blades and soft contact shading at roots, without a solid ground disk, planter, scenery, text or unrelated objects.

Plant variants: `0` new sapling or leaf shoots, `1` young plant/buds, `2` flowering, `3` mature fruit tree/full flower bed. Each species has four distinct drawings; rendering scales each stage about its fixed ground anchor. The existing 0/5/10/20 lesson thresholds and individual planting dates are unchanged.

Decorations: apple, pear and sakura; daisies and tulips; birdhouse on a pole; rocking chair facing the bridge (legacy `fence` ID); mushrooms; gardening gnome; fishing gnome facing left with line into the river; wooden bridge; bench; pond with ducks; picnic; tall bronze lantern; orange and cream butterflies. Garland spans apple → sakura → pear, with support posts until the respective trees mature.

`meadow` and `meadow-river` are empty scene plates. `complete` is the approved mature composition, displayed only when every decoration is owned, visible and every plant is fully grown. Hiding any item or planting a new plant returns to individually rendered layers.

This is a presentation-only change. Do not alter catalog IDs, costs, garden version, rewarded lessons, balances, ownership, visibility or planting dates to install artwork. No database migration or reset is required.
